# Dataset Dictionary Drafter

For each field, distinguish observed examples from documented meaning. Capture units, grain, null conventions, valid values and ownership only where known. Treat apparent identifiers and inferred joins as hypotheses. Use synthetic examples for sensitive fields. Finish with questions that unblock interpretation of ambiguous columns.
